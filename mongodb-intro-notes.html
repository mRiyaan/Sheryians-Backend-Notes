01

Database & MongoDB

Why variables aren't enough & SQL vs NoSQL terminology

Database: A system used to persist, organize, retrieve, and update application data.

Why do we need a database?

Data stored only in a Node.js variable disappears when the server restarts. A database keeps data persistent.

MongoDB is a document-oriented NoSQL database.

02

Atlas, AWS & Cluster

Managed cloud deployments vs raw infrastructure

MongoDB Atlas is MongoDB's managed cloud service. It hosts MongoDB deployments so you don't have to install and manage MongoDB on your laptop or server.

Where does AWS come in?

AWS is a cloud provider. Atlas can run MongoDB on AWS infrastructure. You normally do not create an EC2 machine just to use Atlas.

03

MongoDB Compass

Visual desktop GUI client vs cloud service

Compass is a desktop GUI for MongoDB. It helps you visually inspect databases, collections, and documents.

MongoDB AtlasMongoDB Compass
Cloud serviceDesktop GUI
Creates / manages deploymentExplores data visually
Provides connection detailsConnects using URI
Remember

Compass is not the database. It is a visual client used to connect to and explore MongoDB.

Typical connection URI:

mongodb+srv://username:password@cluster.mongodb.net/myDB
04

Mongoose & Connection

Schemas, Models, and ODM conveniences

Mongoose is an ODM (Object Data Modeling library) for MongoDB and Node.js. It provides schemas, models, validation, and convenient database APIs.

const mongoose = require("mongoose");

const userSchema = new mongoose.Schema({
  name: String,
  age: Number
});

const User = mongoose.model("User", userSchema);

Connect to Atlas:

require("dotenv").config();
mongoose.connect(process.env.MONGODB_URI);
Important Security Rule

Keep the MongoDB URI in .env. Never commit database credentials to GitHub.

06

Create a MongoDB Atlas Cluster

10-step cloud checklist
  1. Create / sign in to MongoDB Atlas
  2. Create a Project
  3. Create a deployment / cluster
  4. Select a cloud provider such as AWS
  5. Select a nearby region
  6. Choose the appropriate Free / Flex / Dedicated option
  7. Create the deployment
  8. Security: Create a Database User (username & password)
  9. Security: Add your IP address to Network Access / IP Access List
  10. Click Connect and copy your connection string
AWS ≠ Atlas

AWS provides cloud infrastructure. Atlas manages MongoDB on that infrastructure.

07

Connect Node.js to MongoDB Atlas

Installation, .env configuration, and connection promise

1. Install packages:

npm install express mongoose dotenv

2. Configure .env:

MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/myDB

3. Connect in Node.js:

const mongoose = require("mongoose");

mongoose.connect(process.env.MONGODB_URI)
  .then(() => console.log("MongoDB Connected"))
  .catch(err => console.error(err));
